# Visão do Projeto

## Objetivo

Criar e manter um site institucional moderno para a **Trimmos Barbearia**, com foco em apresentação da marca, serviços, profissionais, trabalhos, avaliações, localização e contato.

O projeto é um **site estático/vitrine**.

### Não é objetivo do projeto

- Criar um sistema próprio de agendamento.
- Substituir o sistema externo de agendamento.
- Transformar o site em uma aplicação SaaS.
- Criar banco de dados para reservas.

O site pode direcionar o cliente para o sistema externo de agendamento utilizado pela barbearia.

## Prioridades

1. Profissionalismo
2. Fidelidade à identidade da Trimmos
3. Experiência mobile
4. Conversão
5. Performance
6. SEO

## Público principal

Mais de 95% dos acessos previstos são pelo celular.

Por isso, mobile-first é uma prioridade do projeto.

## Histórico da marca

- Nome atual: **Trimmos Barbearia**
- Nome histórico: **Barbearia Hunziker**
- Desde: **2020**

O nome Hunziker deve aparecer apenas como referência histórica quando fizer sentido.
