# Regras do Projeto

## 1. Site estático

O TRIMMOS é uma vitrine institucional.

Não transformar o projeto em sistema próprio de agendamento.

## 2. Mobile-first

Prioridade:

1. Celular
2. Tablet
3. Desktop

Larguras importantes para teste:

- 360px
- 390px
- 414px
- 768px
- 1024px
- 1280px
- 1440px

## 3. Experiência

- Sem rolagem horizontal.
- Áreas clicáveis/touch com pelo menos 44px quando aplicável.
- CTAs importantes facilmente acessíveis.
- Texto legível.
- Contraste adequado.
- Navegação simples.

## 4. Performance

- Otimizar imagens.
- Usar dimensões adequadas.
- Lazy load quando apropriado.
- Evitar embeds pesados.
- Carregar mapa/vídeo sob demanda quando possível.

## 5. SEO

Produção deve possuir:
- title;
- description;
- Open Graph;
- favicon;
- dados estruturados adequados;
- endereço;
- telefone;
- horários;
- links oficiais;
- canonical correto.

Preview:
- `noindex`;
- `nofollow`;
- sem canonical de produção.

## 6. Imagens

Priorizar imagens:
1. fornecidas pelo projeto;
2. autorizadas pelo proprietário;
3. atuais e coerentes com a marca.

Não copiar em massa imagens de redes sociais apenas por estarem públicas.

## 7. Alterações

Toda mudança importante deve:
- ter motivo;
- ser testada;
- ser revisada;
- ficar documentada quando alterar uma decisão do projeto.

## 8. Produção

Nenhuma mudança em produção sem aprovação do proprietário.
