## Como usar

A pasta `docs/` do repositório **é o próprio Vault** do Obsidian.

1. Clone o repositório (veja [[02 - Ambiente de Desenvolvimento]]).
2. No Obsidian: **Abrir pasta como vault** (*Open folder as vault*) → selecione a pasta `TRIMMOS/docs`.
3. Comece por [[00 - Início]] (também fica nos favoritos/*Bookmarks*).

O Obsidian reconhecerá os arquivos Markdown e os links `[[...]]` automaticamente.

A documentação é versionada no Git junto com o código: alterações nas notas seguem o mesmo fluxo de branch, revisão e commit (veja [[12 - Trabalho em Equipe]]).
