# Checklist de Alterações

Use esta checklist antes de considerar uma alteração pronta.

## Desenvolvimento

- [ ] Entendi o objetivo da alteração.
- [ ] Confirmei se a informação é verdadeira.
- [ ] Trabalhei na branch/repositório correto.
- [ ] Não alterei `main` de produção indevidamente.

## Visual

- [ ] Mobile 360px
- [ ] Mobile 390px
- [ ] Mobile 414px
- [ ] Tablet 768px
- [ ] Desktop 1024px
- [ ] Desktop 1280px
- [ ] Desktop 1440px
- [ ] Sem rolagem horizontal.
- [ ] CTAs funcionando.
- [ ] Menu funcionando.
- [ ] Imagens sem quebras.
- [ ] Texto legível.

## Funcional

- [ ] Links internos funcionando.
- [ ] Links externos funcionando.
- [ ] WhatsApp funcionando.
- [ ] Instagram funcionando.
- [ ] Google Maps funcionando.
- [ ] Botões funcionando.
- [ ] Não há erro no console.
- [ ] Não há imagens quebradas.

## Performance/SEO

- [ ] Build concluído.
- [ ] HTML válido.
- [ ] Links validados.
- [ ] Imagens otimizadas.
- [ ] Meta tags conferidas.
- [ ] Canonical correto em produção.
- [ ] `noindex` presente no preview.
- [ ] Dados estruturados conferidos.

## Antes de produção

- [ ] Proprietário aprovou.
- [ ] Todas as alterações solicitadas foram concluídas.
- [ ] Backup disponível.
- [ ] Diff revisado.
- [ ] Commit revisado.
- [ ] Merge autorizado.
- [ ] Site oficial validado após publicação.
